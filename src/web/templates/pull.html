🌐 Pull 数据源（让 ChatLab 直接拉取）

开启后 ChatLab 可通过「远程数据源 / Remote Data Source」直接读取本机聊天记录，无需先导出文件； 支持全量拉取与增量续拉（since 游标）。服务运行在本程序内部，关闭本程序即自动停止。

提示：ChatLab 会自动在地址后补 /api/v1（填 http://127.0.0.1:8765 时它请求的是 http://127.0.0.1:8765/api/v1/sessions）。本服务已同时支持根路径与 /api/v1 前缀， 两种地址都可以直接填。

ChatLab 端操作步骤

  1. 本页点击「启动服务」，等待状态变为 运行中（首次会先扫描会话，约 1-3 秒）。
  2. 打开 ChatLab → 设置 / 数据源 → 添加远程数据源（Pull）。
  3. 地址填上面显示的 Url（本机用 127.0.0.1，手机端请用 0.0.0.0 模式给出的局域网地址）。
  4. 若设置了 Token，在 ChatLab 的 Token / 认证 一栏填入相同值。
  5. 选择要拉取的会话即可，已拉取过的会话再次同步时会自动增量续拉。

不想用远程数据源？也可以到 聊天导出 选择 ChatLab JSONL 导出文件后手动导入。

协议接口（chatlab-pull/v1）

方法路径说明
GET/sessions会话列表，支持 keyword / limit / cursor 分页
GET/sessions/<id>/messages消息内容，format=chatlab，支持 since / limit
GET/push/messagesSSE 增量推送（可选）
GET/health健康检查

以上端点同时注册在 /api/v1/... 前缀下——ChatLab 客户端请求的正是该前缀（它会把填入的地址自动规范化为 <地址>/api/v1），两种写法完全等价。

========================================
  WeChat Export（微信导出）使用说明
  维护者：yuuu
  仓库：https://github.com/yuuuzzh/wechat-export
========================================

【这是什么】
WeChat Export（微信导出）：把电脑版微信聊天记录做本地分析与导出（Excel / 网页 / 报告）。
程序只在你自己电脑上运行，不会把聊天内容上传到互联网。
使用前请阅读仓库 README 中的完整免责声明与使用条款。

【使用前准备】
1. 电脑是 Windows 10 或 Windows 11（64 位）
2. 已安装「微信电脑版」4.x，并且能正常登录
3. 杀毒软件如果拦截，请选择「允许」或加入信任（本程序会读取微信本地数据，容易被误报）

【怎么用（一共 3 步）】
第一步：打开电脑版微信，登录你的账号（保持登录状态）
第二步：双击本文件夹里的 wechat_exp.exe
       - 会弹出一个黑色小窗口，请不要关闭它
       - 浏览器会自动打开操作页面；如果没有，请手动打开浏览器访问：
         http://127.0.0.1:5000
第三步：在网页里按顺序点：
       1）「一键备份」→ 等它跑完（首次可能要几分钟）
       2）「聊天导出」→ 勾选会话 → 可选关键词 → Excel/HTML/会话报告包 等 → 开始导出
         也可去「全局搜索」检索后一键导出命中结果
       3）导出完成后点下载，保存到桌面即可

【日常再用】
以后如果只是查旧记录：直接双击 wechat_exp.exe，不用每次都备份。
只有微信里又聊了很多新内容、想更新时，再点一次「一键备份」。

【不要发给别人的文件】
用完后文件夹里可能出现 backup、export、.wechat_exp_config.json 等。
里面有你的聊天数据和密钥，不要打包发给别人，也不要传到网盘公开分享。

【常见问题】
Q：双击没反应 / 被杀毒删了？
A：到杀毒软件「隔离区」恢复，并把 wechat_exp.exe 加白名单。

Q：黑色窗口关掉了网页打不开？
A：黑色窗口就是程序本体，关掉就等于退出。请重新双击 wechat_exp.exe。

Q：备份提示找不到微信 / 密钥不足？
A：确认微信已登录且正在运行，再点仪表盘里的「提取密钥」，然后重新「一键备份」。

Q：要不要安装 Python？要不要点「安装依赖」？
A：不需要。发给你的这个绿色版已经打包好，双击 exe 即可。

【重要提醒】
请只导出、分析你自己的聊天记录。未经他人同意，不要获取或传播他人隐私数据。

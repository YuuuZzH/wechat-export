# WeChat Export · 微信导出

> **维护者**：yuuu · **仓库**：https://github.com/YuuuZzH/wechat-export  
> **版本**：2.11.20261011 · **平台**：Windows 10/11 · **微信**：4.x（已测 4.1.9 / 4.1.10 / 4.1.12.55 / 4.1.15.11）  
> **定位**：本地完成微信聊天记录的**分析、搜索与多格式导出**（备份是前置步骤）

数据默认不出本机 · 可执行文件名 `wechat_exp.exe`（兼容分享包与旧脚本）。界面主题可切换（像素风 / 青春风 / 科技风 / 动漫风 / 微信原始风 / QQ 复古风等，持续完善）。

> 文档截图中的会话名、头像、路径、消息正文均为**演示占位**（统一示例头像、`示例群聊` / `联系人甲` / `wxid_demo` 等），已脱敏，不对应真实账号。

## 核心能力

| 能力 | 说明 |
|------|------|
| 多选导出 | 勾选多个群聊/私聊，一次导出 |
| 关键词过滤 | 只匹配消息正文（空格 = AND，`\|` = OR）；ChatLab 格式同样支持 |
| Excel 时间线 | 多会话按时间平铺，己方消息浅橙底 |
| 会话报告包 | 对话 HTML + 词云 + 统计 JSON，打成 ZIP |
| 全局搜索 | FTS 索引 + 正则 / 发送者 / 类型；命中可一键导出 Excel / HTML / CSV / TXT |
| 语音导出 | 按人聚合、独立离线 HTML、合并音频 |
| 综合 / 年度 / 词云 | 图表报告离线可用（不依赖 CDN）；年度报告可限定单个会话 |
| Pull 数据源 | 供 ChatLab 远程增量拉取 |

## 1. 快速开始

双击 `wechat_exp.exe`（或 `start.bat`）即可，无需安装 Python。

```
① 登录微信（4.1.10+ 可保持运行；更早版本建议登录后尽快备份）
② 打开程序 → 浏览器访问 http://127.0.0.1:5000 → 点「一键备份」
③ 备份完成后，用「聊天导出 / 全局搜索 / 报告」做分析与导出
```

### 3.2 一键备份（首次必做）

1. 确认微信已登录（4.1.10+ 无需重启）  
2. 仪表盘 → **一键备份**  
3. 确认数据目录与日期范围 → **开始备份**  
4. 等待：扫描 → 解密 → 迁移媒体 → 构建索引  

找不到目录时可用「自动检测」「深度搜索」，或从微信「设置 → 文件管理 → 打开文件夹」粘贴 `db_storage` 路径。

![备份页](screenshots/03-backup-page-masked.png)  
*图 3：一键备份 — 目录与日期*

| 阶段 | 说明 | 大约耗时 |
|------|------|---------|
| 扫描 | 查找账号与数据库 | 数秒 |
| 解密 | 解密库；缺密钥时自动从进程提取 | 10–60 秒 |
| 迁移 | 复制图片 / 视频 / 语音 / 文件 | 1–5 分钟 |
| 索引 | 构建统一索引（含搜索） | 10–30 秒 |

![备份进度](screenshots/04-backup-progress-masked.png)  
*图 4：备份页面与进度区域*

结果默认在 exe 同目录的 `backup\` 下。无新消息时不必反复备份。

## 5. 图片显示（V2 / wxgf）

### V2 加密图

密钥仅在微信运行时内存中。若提示「V2 加密图片」：登录微信 → 在对应聊天里滚过这些图片 → **提取密钥** → 刷新查看器。

### wxgf（H.265）

部分原图需 ffmpeg 转 JPEG。页面可「一键安装 ffmpeg」，或把 `ffmpeg.exe` 放到程序目录 `tools\`。无 ffmpeg 时会退回显示缩略图。

## 6. 常见问题

**Q：双击没反应？**  
查杀软拦截；把 `wechat_exp.exe` 加白名单。

**Q：弹出黑窗口？**  
正常。那是本地服务控制台，**不要关**，关掉服务就停了。

![控制台](screenshots/15-console-window-masked.png)  
*图 25：控制台窗口*

**Q：浏览器没自动开？**  
手动访问 `http://127.0.0.1:5000`。

**Q：找不到微信数据目录？**  
用备份页「自动检测 / 深度搜索」，或从微信设置打开文件夹后粘贴 `db_storage`。

**Q：密钥不足？**  
4.1.10+：微信登录中点「提取密钥」。更早版本：退出 → 重登 → 立刻备份/提取。

**Q：语音 404？**  
会遍历全部 `media_*.db`；仍失败则重新做一次一键备份。

**Q：上传我的聊天吗？**  
不会。分析与导出均在本地。仅当您主动选用「百度语音识别」时，对应音频会发往百度接口。

**Q：页面空白？**  
`Ctrl+F5` 强刷，或换 Edge/Chrome 后重启程序。

更多细节见程序内 **说明**（顶栏「说明」，内容与本 README 同步），或本仓库 README。

## 7. 命令行参考（高级）

源码运行示例（在项目根目录）：

```bash
# 启动 Web
python src/main.py serve --host 127.0.0.1 --port 5000

# 一键备份
python src/main.py backup

# 导出聊天
python src/main.py export -m chat --chat 张三 --format html

# 词云 / 综合报告
python src/main.py export -m wordcloud --chat 张三
python src/main.py export -m report --year 2025

# ChatLab Pull
python src/main.py chatlab-pull --host 127.0.0.1 --port 8765

# 导入密钥
python src/main.py import-keys --list
python src/main.py import-keys --file keys.txt

# 语音导出
python src/main.py voice-export --chat 家族群 --merge-by person --format mp3
```

打包 exe 后，把上面的 `python src/main.py` 换成 `wechat_exp.exe` 即可。完整参数见 `python src/main.py -h`。
